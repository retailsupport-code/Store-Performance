Update Dashboard Data

This dashboard now loads live from your published Google Sheets automatically. Use this manual upload only as a one-off override or if a live fetch fails — all processing happens in your browser, nothing is uploaded anywhere.

File formats needed (CSV, not Excel):
1. Current-year sales — columns must include Location, Bill Date (DD-MM-YYYY), Bill Code, Product, Bill Amount, Net Qty, Salesman
2. Last-year sales — same columns, same months as the current-year file (e.g. if uploading August, include August of last year)
3. Store targets — columns: STORES, Store Category, then one column per month (header = month name, e.g. AUGUST). You can include just the new month's column, or the whole file — existing months are merged, not replaced.
4. Staff targets (optional) — columns: Store, Staff Name (or "Staff"), Month, Target (or "Gross Target"). Leave a row's Target blank if you haven't decided yet — that staff just falls into the normal equal split. Enter 0 for a store manager — they'll show sales but no target, and won't be counted in anyone else's equal split. Any staff not listed at all also get an equal split of what's left over.
Tip: in Excel, use File → Save As → CSV for each sheet/file.

Mid-month uploads: if your current-year file only covers part of a month (e.g. 1–14 August), that's fine — the dashboard shows your actual sales as-is, and automatically compares against the same date range last year (1–14 August last year) instead of the full month, so growth% stays fair. It'll say so in the Month Performance section when this applies.
